# 報告-構造

> - 抽出元: 報告6件（FHB 24/08, HB 25/01・25/03/26・25/04/22, 2DEE 25/07/18, 本部長 25/10/15）
> - 信頼度: **高**（6件で共通構造を実証）
> - 前提: `共通基盤-構造.md`（表紙/大日程/体制図/用語説明/Appendix/トーン）

---

## 目的・読者・ゴール
- 目的: 案件の状況を共有し、判断・方針を仰ぐ
- 読者: 本部長・部長（FHB／HB／本部長報告）
- ゴール: 現状と論点を正しく伝え、**現場の機微まで共有**する

## スライド構成（標準フロー）

```
表紙 → ①趣旨 or 目次 → ②背景・概要(用語説明含む) → ③大日程(任意) → ④体制
   → ⑤取り組み状況(本体・複数枚) → ⑥今後の進め方 → ⑦★所感/課題/学び → 以上 →(Appendix)
```

③大日程・④体制は、長期案件や新規立ち上げで入れる（短い経緯報告では省略可）。

---

## 各スライド型

### ① 趣旨 / 目次（冒頭）★テーマ数で型を選ぶ
- 役割: 今回の報告の位置づけ・**前回からの差分**を示す
- **趣旨型**（単一テーマ・経緯報告）— 「報告の趣旨」1枚に要約
  - 実例: 「デジタル家系図の部品標準化範囲との位置付け・進め方を、昨年末よりEDCと調整してきましたので取り組みを報告します」(0326)
  - 実例: 「中止については既報の通り。プロジェクトの中（特にメンバー）の状況を共有いたします」(0422)
- **目次型**（複数テーマ・情報量多い）— 「目次」に趣旨(前回差分)＋アジェンダ
  - 実例: 「前回(7/18)は法規認証TPS案件参画とRxSWIN立ち上げを報告。8/18からRxSWIN案件が開始。取り組み状況を共有」＋目次（案件概要/取り組み状況/今後の進め方/所感）(1015)
- 必須要素: 前回からの差分 / 今回伝えること /（目次型は）アジェンダ

### ② 背景・概要
- 役割: 案件の背景・スコープ・全体像を共有
- メッセージライン例: 「部品リスト出力の概要：車種・法規ごとに適切なSW品番を出力しSWINを付与する」(1015 s5)
- 必須要素: 背景 / スコープ /（必要に応じ）用語説明（→共通基盤）
- 図表タイプ: 文章＋概念図

### ⑤ 取り組み状況（本体）
- 役割: 進捗・わかったこと・直面した課題を**複数枚**で語る。報告の中核
- メッセージライン例:
  - 「約2か月の取り組みで、RxSWIN要件や業務フローの整理を進めシステム化の全体像が見えつつある」(1015 s9)
  - 「事前検討情報から具体・詳細を整理。法規認証系のシステムと連携する必要性が見えてきた」(1015 s12)
- 必須要素: 1スライド=1メッセージ＋事実＋(あれば)図示。複数論点は**1論点1枚**に割る
- 図表タイプ: 文章＋概念図 /（経緯は）調整サマリー表
- 補足: 経緯を時系列で示すときは「調整サマリー」表（日付 / 関係者列 / 内容）→ `図表パターン.md`。実例: 2/14・2/25・3/14のTS内部長間の動き (0326 s5-8)

### ⑥ 今後の進め方
- 役割: 次に何をするか・論点をどう詰めるか
- メッセージライン例: 「ロジック検証を行い要件を固め、1月から開発着手を目指す」(1015 s14)
- 必須要素: 次アクション / 依存・リスク / 目標時期

### ⑦ ★所感 / 課題 / 学び（締め・最重要）
- 役割: 事実の先にある**現場の機微・主観・洞察**を率直に伝える。**この報告の魂**。事務的に薄めない
- 呼称の揺れ: 所感 / 課題 / 学び / 残課題 / メンバーの受け取り（テーマで使い分け）
- 書き方の型: **事実 → 主観・解釈 → 含意（対策 or 心情）**
- メッセージライン例（率直さを保つ）:
  - 「ユーザー側（法規認証部）が一歩引いた様子（受け身）のため、TSが仮説を立ててぶつけていく必要あり」(1015 所感)
  - 「業務を変えることに対して事務局が壁になっていることが理解できた」(FHB 課題・所感)
  - 「会話の中で棘を感じることもあったが、植田部長・髙綱GMとは…」(0326 学び)
  - 「残念な気持ちはあるが、チームを抱える身として、今後の心配が勝っている」(0422 所感)
  - 「普通に悲しい、ただただ残念」(0422 メンバーの受け取り)
- 必須要素: 主観を含む洞察 / 人間関係・力学の機微 / 次への含意
- ⚠ **ここを当たり障りなく薄めない。率直さ・生々しさがこの報告の価値。**

## この報告者（ヤマモト）の作法メモ
- 経緯は**日付で時系列**に示す（調整サマリー・日付別の動き）
- 関係者の反応・力学を率直に書く（誰が壁／受け身／棘を感じた）
- 事実と所感を必ずセットで上司に渡す（肌感の共有を重視）
