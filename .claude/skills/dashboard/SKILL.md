# ダッシュボード再生成スキル

ルートの `ダッシュボード.md` を、全PJの最新データから再生成する。これは派生ビュー（読み取り結果の出力）なので、ユーザーの依頼があればいつでも再生成してよい。

## 手順

### 1. 現在時刻の確認
`date` コマンドで日付・時刻を取得し、ヘッダの「最終更新」に使う。

### 2. データ読み込み
- 全PJの `.ai-secretary/projects/<PJ>/tasks.json`（アクティブ）
- 全PJの `.ai-secretary/projects/<PJ>/tasks_archive.json`（完了・取り下げ。直近の完了表示用）

### 3. 分類ルール
- **自分のタスク**: `assignee` が `null` または `"ヤマモト"`
  - `📋 todo`: status が `todo` / `in_progress`、かつ `starts_at` が未来でないもの
  - `⏸️ 待機中`: `starts_at` が今日より未来のもの
  - `❓ 保留確認`: status が `waiting` のもの
- **👀 ウォッチ中**: `assignee` が自分以外（人名・役割表記）。PJごとにグループ化
- `suspended` のタスクは**表示しない**（PJ再開時に復活）
- `dropped: true` は表示しない

### 4. 出力フォーマット（既存の ダッシュボード.md に踏襲）

> 表（テーブル）＋ TODO全件の箇条書き で出す。コードブロックだけにしない。重複する列は作らない（「必要アクション」列があるなら「課題」列は省く 等）。

```
# タスクダッシュボード

> 最終更新: YYYY-MM-DD HH:MM（再生成）
> 「全タスク見せて」または「ダッシュボード更新して」で再生成できます。
```

### 5. 書き込み
- `ダッシュボード.md`（プロジェクトルート）を上書きする
- 該当タスクが0件のセクションは見出しごと省略してよい（空テーブルは出さない）

## 注意
- これは派生ビュー。元データ（tasks.json）は変更しない
- 期限は `deadline.type`（hard/soft/asap/none）と `date` を併記し、過去日付なら「超過」と明示する
