description: レビューFBを記録し、レビュアーの傾向を学習する
argument-hint: "<task-id> --from <レビュアー名> --fb <フィードバック内容>"
---

レビューフィードバックを記録してください。

## 手順（必須）

1. **該当PJの knowledge.md と people.md を読み込む**（レビュアーの既存傾向を把握）

2. **tasks.json の該当タスクの `review_history` にFB内容を追加**
   ```json
   { "reviewer": "レビュアー名", "date": "YYYY-MM-DD", "feedback": "FB内容", "resolved": false }
   ```

3. **該当PJの `people.md` にレビュアーの傾向を追記**
   - 日付を必ず記録する
   - 例: 「2026-03-28: 結論ファーストを求める指摘 → 結論ファースト重視の傾向」

4. **`global/people.md` の該当者にも全般的な傾向として反映**
   - PJ固有でなく、その人の全般的なレビュー傾向を記録する

5. **保存後に構文確認**（tasks.json は読み直して構文チェック）

6. **傾向の分析をユーザーに共有**
   - 過去のFBと比較して、一貫した傾向があれば伝える
   - 例:「この方は3回連続で構成の指摘をしています。次回は構成を先に見せると良いかもしれません」
