# 人物クイックブリーフ スキル

指定された関係者1人について、散らばった情報を1枚に集約して即答する。

## 参照するデータ

1. `.ai-secretary/global/people.md` — 組織共通の関係者マスタ
2. 各PJの `.ai-secretary/projects/<PJ>/people.md` — PJ固有の情報（全PJを横断検索）
3. `.ai-secretary/global/review/people/<名前>.md` — レビュー傾向（あれば）
4. `.ai-secretary/global/patterns.json` の `observations` — その人物に言及した暗黙知・力学（type: knowledge / preference 等）

## 手順

1. 入力された名前を**カタカナ**で正規化する（音声認識由来の表記ゆれ・既知の誤変換に注意。knowledge.md の補正情報も参照）
2. 上記データを横断し、その人物の情報を集める
3. 複数PJに登場する場合は、PJごとの立場の違いも示す
4. 見つからない／同名が複数いる場合は、その旨を伝えて確認する（勝手に推測で断定しない）

## 出力フォーマット

```
## 👤 <名前>（<役職>）

- **立場・関係**: <自分との関係。上司/レビュー者/依頼元 等>
- **力関係・頼み方**: <直接OK / GM経由 / TL経由 等。根回しの順序があれば>
- **レビュー傾向**: <結論ファースト重視・数字重視・細部指摘 等。patterns.json の定量（過去N回中M回○○を指摘）があれば添える>
- **関わるPJ**: <PJ名（PJごとに立場が違えば併記）>
- **直近のやりとり・行間**: <observations から拾った最近の評価・温度感・暗黙知>
- **⚠ 注意点**: <地雷・避けるべき進め方があれば>
```

- 該当データがない項目は省略する（無理に埋めない）
- 最後に「もっと詳しく知りたければ people.md を見ますか？」等、深掘りの導線を一言添えてもよい

## 注意
- これは読み取り・集約のみ。people.md は更新しない（更新が必要なら knowledge-base スキルへ）
- レビュー傾向は「過去の事実」。決めつけず「〜の傾向」と表現する
